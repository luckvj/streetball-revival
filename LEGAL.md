## What this repository contains

- Only this project's own source code, tools and documentation, and images
  made by the project (the launcher's screenshot and diagrams).
- No disc images, executables, extracted files, art, models, music, voice,
  movies or saves from the original game, and no code copied from it.
- The program reads the game's data at runtime from a disc image the user
  supplies from their own copy. Nothing from the disc is uploaded, shared or
  sent anywhere; online play exchanges only button presses and a check that
  every player's disc is the same release.

## Your responsibilities
