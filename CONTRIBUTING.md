# Contributing

Thanks for helping. A few rules keep the project healthy and legal.

## The hard rule: no game data

Never commit, attach or link anything from the original disc: disc images,
extracted files, textures, models, audio, movies, saves, or code copied from
the original program. The program reads all of that from each player's own
disc at runtime. `python tools/publish_check.py` must say `clean` before
every push (CI runs it too).

Keep the original's publisher, developer and league names out of code,
comments and docs; the one place they appear is [LEGAL.md](LEGAL.md). Refer
to "the original game" or "the original" instead. The publish check catches
the common cases.

## Reporting bugs

Say what you did, what you expected and what happened, with your OS and
controller. A screenshot of Streetball Revival is fine; please don't attach
disc images or game files.

## Changing behaviour

The goal is 1:1 with the original. A change that alters gameplay should say
what the original does and how that was established (a trace of its program,
or a recording of it running), in the commit message and, for anything
non-obvious, in `docs/TRACE.md`. The parity scorecard
(`docs/PARITY_SCORECARD.md`, generated by `tools/parity_scorecard.py`)
records what has been checked and how.

## Before a pull request

```sh
cargo fmt --all
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
python tools/publish_check.py
```

Set `STREET_ISO` to your own disc image's path to also run the checks
against the disc.
